# Face and Emotional Recognition System

## Overview

Face and Emotional Recognition System is a web application developed using the Django Framework, OpenCV, and Machine Learning techniques. The project combines Face Identity Recognition and Facial Emotion Recognition into a single intelligent web application.

The system can identify one of 11 well-known public figures and classify facial emotions into three categories:

* Happy 😊
* Angry 😠
* Neutral 😐

This project was inspired by concepts from Artificial Intelligence, Machine Learning, and Computer Vision, focusing on the practical implementation of face detection, face recognition, emotion classification, and web deployment.

## Machine Learning Concepts Applied

This project incorporates several Machine Learning and Computer Vision concepts, including:

* Image preprocessing using OpenCV
* Face detection with Deep Neural Networks
* Feature extraction from facial images
* Face identity classification
* Facial emotion classification
* Model evaluation and optimization
* Integration of machine learning models into a production-ready web application

The project demonstrates how machine learning pipelines can be connected with Django's Models, Views, and Templates (MVT) framework to create an interactive AI-powered web application.
